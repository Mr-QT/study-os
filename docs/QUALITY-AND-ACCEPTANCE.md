# 完整质量工程与真实场景验收规范

## 测试层级

1. 单元：领域规则、时间/时区、权限、统计去重、预算、自动化循环保护。
2. 集成：API + PostgreSQL、文件存储、任务队列、同步协议、权限拒绝。
3. E2E：Playwright 驱动真实前后端和测试数据库，验证用户旅程；外部付费模型可 mock，但必须另设受控真实集成 smoke test。
4. 离线/多端：断网创建、编辑、删除、重连、重复提交、并发冲突、设备撤权。
5. 安全：越权、上传恶意内容、提示注入、AI 工具权限、插件隔离、密钥泄漏。
6. 视觉/无障碍：响应式截图、长文本、中英切换、键盘、读屏、对比度、axe。
7. 运维：迁移、备份恢复、升级兼容、通知失败重试、容量阈值与预算阻断。

## 关键端到端用例（必须落地）

| ID | 场景 | 可验证预期 |
|---|---|---|
| E2E-01 | 新建课程→作业→任务→日历→通知 | 关联一致、唯一主记录、正确时区 |
| E2E-02 | AI 拆解任务→用户确认→写入 | 未确认不修改数据；确认后审计可见 |
| E2E-03 | 专注计时→笔记→学习日志→统计 | 时长与任务/课程关联，刷新后仍存在 |
| E2E-04 | 离线编辑→重启 PWA→联网同步 | outbox 持久、无数据丢失、状态可见 |
| E2E-05 | 双设备同时修改同一笔记 | 冲突提示/版本保留，不能静默覆盖 |
| E2E-06 | 私密空间请求云端 AI | 默认拒绝；明确授权后才允许发送限定内容 |
| E2E-07 | 自动化重复触发或循环 | 幂等、深度限制、费用限制、停止开关有效 |
| E2E-08 | 用户撤销共享权限 | 相关 API、同步、检索和插件访问拒绝 |
| E2E-09 | 导入旧数据→预览→确认→撤销 | 原件不丢失，重复检测可解释 |
| E2E-10 | 数据库升级失败→恢复 | 数据完整性校验通过，恢复步骤可执行 |
| E2E-11 | 中英切换、深色/高对比度、键盘导航 | 无关键缺字/溢出/不可操作控件 |
| E2E-12 | AI 预算耗尽 | 后续请求被阻断或需审批，费用状态清楚 |

## 每里程碑必须提交的证据

- Git commit/hash 与变更文件清单；功能列表 `DONE/PARTIAL/PLANNED/BLOCKED`。
- 本地运行命令、必要环境变量、实际访问地址（由运行环境生成，不得编造）。
- 测试命令、通过/失败数量、失败原因、未运行项目及原因。
- 桌面/平板/手机关键页面截图；不允许用设计稿替代真实应用截图。
- 至少一条跨模块真实数据库流程；必要时提供测试数据创建/清理脚本。
- 数据迁移、隐私、安全和已知风险说明。
- 用户验收清单与明确“是否批准下一里程碑”请求。

## Definition of Done

代码可运行 + 数据真实持久化 + 权限/隐私合规 + 自动化测试有证据 + 可访问性与响应式检查 + 文档同步 + 用户验收。仅 UI 完成、只用 mock、无数据持久化或未验证的功能不可标记 DONE。
