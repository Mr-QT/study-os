# 隐私、安全、授权与数据控制

## 数据分级（默认最小权限）
- `PUBLIC/SHARED`：明确共享范围内的内容；共享不等于可用于外部 AI。
- `PERSONAL`：个人默认数据；云端 AI 仅在已授权服务商/用途/空间范围内使用。
- `PRIVATE_LOCAL`：仅本地数据，默认禁止同步、云端 AI 和第三方插件读取。
- `SENSITIVE`：高敏内容；需更细粒度确认、脱敏与审计。

**判定顺序**：空间/文件隐私等级 → 用户授权 → Agent/插件能力 → 服务商目的 → 预算与速率 → 模型路由。任何拒绝都不能被智能路由绕过。

## 身份与协作
- 支持无账号本地访客；账号、设备会话、撤销与安全恢复逐阶段上线。
- 分享由资源所有者显式发起；查看者/编辑者/管理者权限服务端验证。
- 不实施企业级组织层级和复杂实时协同编辑（第 24 项）。

## 密钥与加密
- API Key 仅存于受保护的服务端密钥存储或用户设备受保护存储；绝不在前端公开环境变量或日志中暴露。
- HTTPS/TLS；数据库和对象存储静态加密；备份加密与恢复验证。
- 端到端加密为可选架构：若启用 E2EE，服务器不得假装能同时明文索引/AI 分析。任何显式云端解密处理必须由用户授权。

## AI 安全
- RAG 来源文档、网页、插件内容视为不可信数据；模型不能凭外部文本扩大权限。
- AI 记忆保留来源与可信度，支持查看/修改/删除/禁用；推断不自动写成事实。
- 高风险动作（删除、批量修改、外发、付款、分享）必须确认、审计并尽可能支持撤销。
- AI 用量按用户/Agent/空间限制，预算超限阻断。

## 生命周期
- 提供导出、迁移、回收站、保留策略、删除请求及备份策略；明确删除在备份中的保留窗口。
- 原始学习资料与 AI 派生内容分开存储，清理前进行引用影响分析。
- 诊断日志脱敏；可选匿名遥测必须显式同意；禁止记录完整私密笔记和凭据。

## 安全测试
权限越权、IDOR、CSRF/XSS、文件上传校验、插件逃逸、同步冲突、提示注入、外发审批、重放与幂等、会话撤销、备份恢复。安全事件有应急响应与审计。
