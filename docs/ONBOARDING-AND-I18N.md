# 首次引导、中英双语和无障碍

## 初始化流程（全部可跳过）
欢迎 → 选择简体中文/English 与主题 → 本地访客或账号 → 选择学习场景/目标 → 建立空间 → 可选导入 → 可选配置 AI/隐私/同步 → AI 推荐布局/计划（需确认） → 进入工作台。

- 每一步可跳过、返回、暂停，设置中可重启向导。
- AI 不可在未授权时读取或上传用户资料；示例空间须显著标记为演示，不混入真实统计。
- 未配置 API Key/云端账号仍可创建课程、任务和笔记。
- 高级功能采用渐进式提示，用户可关闭。

## 国际化
- 首批完整界面支持简体中文和英文；AI 回复语言独立设置。
- 使用翻译 key，不在组件中散落硬编码；通知/邮件/报告都使用中英模板。
- 日期、数字、时区、复数规则使用成熟 i18n/Intl；课程原文语言不随界面切换被改写。

## 无障碍
- WCAG 2.2 AA 目标：语义标签、键盘导航、焦点管理、屏幕阅读器、对比度、可缩放文字、减少动画、足够触控目标。
- 自动化 axe/Playwright 检测 + 人工键盘与读屏测试；自动检测不代表完全符合标准。
