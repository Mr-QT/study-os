# ADR-0006：阶段 1 之前待定的基础设施选型

- 状态：Proposed（仅记录候选，不做决定）
- 日期：2026-10-19
- 影响范围：身份、离线、检索、队列、对象存储、插件沙箱
- 背景与问题：以下选择会显著影响数据模型与安全边界，必须在阶段 1 之前用小规模 spike 验证，不能凭偏好锁定。

## 候选与待验证问题

| 领域 | 候选 | 需要验证 |
|---|---|---|
| 身份 | Auth.js、自建会话、本地访客身份 | 访客→账号合并、设备撤销、2FA 分阶段 |
| 本地存储 | Dexie、idb、自研 IndexedDB 封装 | 事务、outbox 持久化、多标签页一致性 |
| 全文/向量检索 | PostgreSQL 全文 + pgvector、Meilisearch | 中文分词、引用溯源、权限过滤 |
| 任务队列 | pg-boss、BullMQ + Redis | 幂等、重试、延迟任务、Windows 开发体验 |
| 对象存储 | 本地文件、MinIO、S3 兼容 | 去重、版本、引用计数、生命周期 |
| 插件沙箱 | 受限 Worker / 独立进程 | 权限声明、宿主 API 校验、不可信代码隔离 |

- 当前决策：全部**不选**。阶段 0 只交付接口边界与占位约定，不写伪实现。
- 安全/隐私/性能/成本影响：待各项 spike 结果补充。
- 需用户批准：是（进入阶段 1 前逐项确认）
