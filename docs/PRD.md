# Study OS 产品需求文档（PRD）

## 1. 愿景、对象和产品原则
**愿景**：把学习规划、执行、知识积累、复习测评、成长展示连接为一个可持续运行的个人学习操作系统。适用学校课程、自学、考试准备和长期技能发展。主要使用者为个人，允许明确授权的轻量协作。

**原则**：本地优先、用户掌控、可解释 AI、真实数据、可离线、可恢复、渐进式复杂度；AI 提议不等于自动执行；个人数据默认私有。

**主要角色**：个人用户；轻量协作空间成员（查看者/编辑者/管理者）；本地访客；系统管理员（自托管实例）。

## 2. 一级导航与模块需求（最终范围）

| 模块 | 核心能力 | 关键验收示例 |
|---|---|---|
| 首页 AI 驾驶舱 | 可拖拽缩放组件、固定布局、动态简报、时间/场景模式、下一步建议 | AI 建议变化不移动用户固定组件 |
| 学习空间 | 学校→学期→课程等层级，跨空间引用、全局聚合、权限隔离 | 引用同一任务不重复统计 |
| 任务与项目 | 子任务、依赖、重复、优先级、里程碑、看板/甘特/列表、预估与实际、AI 拆解/重排 | 锁定日程不被 AI 改写；依赖无环 |
| 课程 | 课表、单双周、教室教师、考勤、调课、作业、成绩；自建/在线课程、章节进度 | 调课同步日历并产生变更记录 |
| 日历 | 日/周/月、时间块、重复事件、时区、ICS/外部日历、冲突提示 | 课程与任务的日历事件保持一致 |
| 通知 | 站内/PWA 推送/邮件、优先级、勿扰、摘要、失败重试、跨设备 | 关键通知具备送达状态和备用方案 |
| 笔记与知识库 | Markdown/富文本、公式/代码、版本、双链、知识图谱、PDF 标注、OCR、RAG、语义检索 | 引用原文与 AI 生成内容清楚区分 |
| 文件资源 | 多格式导入、目录、去重、版本、注释、音视频处理、权限、对象存储 | 原文件保留，清理前检查引用 |
| 考试与题库 | 考试计划、成绩/GPA、主客观题、模拟考试、错题、雷达图、趋势与风险 | 主观 AI 评分标注非权威与不确定性 |
| 专注与时间 | 番茄钟、正/倒计时、休息、时间块、任务绑定、实际工时、疲劳提醒 | 计时记录可追溯到任务与课程 |
| 学习分析 | 日周月年、目标、掌握度、异常、风险预测、跨空间查询、自然语言分析 | 指标可追溯，预测附依据 |
| AI Hub | 全局聊天、上下文侧栏、选中文本动作、快捷指令、规划/导师/知识/考试/分析 Agent | Agent 工具权限在服务端强制执行 |
| AI 教学 | 学前诊断、先修图谱、苏格拉底式引导、讲授/练习/测验/复盘、主动回忆、间隔重复 | 用户可切换直接回答；薄弱点推断有证据 |
| AI 记忆 | 会话/长期/课程记忆分层、证据、时间、可信度、编辑删除、记忆关闭 | 私密空间记忆不跨边界泄露 |
| 目标成长 | 年/季/月/周目标、路线图、里程碑、技能树、学习档案 | 目标→任务→日志→评估链路可追踪 |
| 习惯激励 | 习惯、打卡、连续天数、XP、徽章、挑战、AI 鼓励、疲劳保护 | 关闭游戏化不影响学习数据 |
| 自动化 | 事件/定时/条件→动作、可视编辑、自然语言规则、AI 建议、审批、干跑、日志、重试 | 幂等、限流、循环保护、暂停开关有效 |
| 插件扩展 | SDK、插件生命周期、权限沙箱、Agent/工作流/页面扩展、API/Webhook | 插件不能默认读取所有学习空间 |
| 多模态 | 语音转写、拍照 OCR、公式、手写、录音、AI 语音对话、快速捕获 | OCR 可校对，保留原始输入；录音需合法授权 |
| 数据迁移 | CSV/JSON/XLSX/Markdown/ICS、Notion/Obsidian 可导出格式、映射、预览、回滚 | 未确认前不覆盖正式数据 |
| 作品集 | 成长档案、里程碑、项目、模板、PDF/Markdown/HTML、权限分享、来源校验 | AI 不虚构成绩/证书 |
| 轻量协作 | 分享笔记/文件/任务、学习小组、任务分配、评论与进度 | 默认私有；不要求企业级实时协同编辑 |
| 设置与安全 | 账号/本地访客、登录、设备、2FA/通行密钥（分阶段）、同步隐私、导出、审计 | 未授权云端 AI 请求被拒绝 |
| 系统健康 | 错误、延迟、任务队列、同步、AI 费用、插件、备份、容量、升级 | 故障有日志且敏感内容被脱敏 |

## 3. 核心用户旅程

**旅程 U1：每日学习闭环**
1. 打开首页，查看课程、任务、考试和建议。
2. 从课程导入作业，关联截止日期和知识点。
3. AI 在授权范围内拆分任务，展示方案，用户确认。
4. 任务与日历/通知联动；用户开启专注会话。
5. 学习中记录笔记、上传材料、查询有来源的 AI 解释。
6. 结束时记录实际时间、进度、掌握证据并更新日报。
7. 离线期间可编辑；联网后同步并处理冲突。

**旅程 U2：备考闭环**：设置考试目标 → 知识诊断 → 生成复习计划 → 错题练习 → 间隔复习 → 模拟考试 → 复盘与计划调整。

**旅程 U3：学习资料迁移**：选择来源 → 映射字段 → AI 识别（可选）→ 预览变更 → 用户确认 → 事务式导入 → 校验与回滚记录。

**旅程 U4：轻量协作**：创建私有空间 → 选择内容 → 邀请成员与角色 → 共享任务和评论 → 撤销权限后访问立即失效。

## 4. 跨模块不变量

- 单个任务有唯一主记录；课程、日历、目标只是引用，不复制事实源。
- 原始文件、原始笔记与 AI 派生内容分开存储，标记生成来源。
- 所有修改可审计；危险操作要求确认并提供可行的恢复机制。
- 本地编辑采用持久化操作队列，跨设备冲突必须可见，不得静默丢弃修改。
- 统计口径统一：任务完成率、时长、课程进度、知识掌握有定义和时间窗口。
- AI 自主执行仅限授予权限；预算/频率/隐私限制均在服务端或本地可信执行层生效。

## 5. 非功能要求

- PWA 离线可用、恢复网络后可靠同步；iOS PWA 后台限制应如实处理。
- 中英双语、WCAG 2.2 AA 目标；键盘与屏幕阅读器支持。
- 隐私最小化、加密传输、静态存储加密、密钥安全、可导出与删除。
- 性能目标在阶段 0 以可测基线确认，CI 持续监控，不凭空保证所有设备的绝对耗时。
- 系统应允许不配置 AI、不登录云端的本地使用路径。

## 6. 范围控制

第一阶段仅交付可运行的核心学习闭环；其他模块完整纳入路线图。高级功能不得以静态演示替代；尚未实现时明确 `PLANNED`。明确不做企业级组织系统和多人实时协同编辑（决策 24）；初始仅完整支持中文/英文（决策 36）；成本功能聚焦智能预算与优化（决策 37）。
